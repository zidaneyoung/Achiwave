# Stage 5 visual direction

## Reference workflow

Stage 5 used the public [Dribbble gaming-app collection](https://dribbble.com/tags/gaming-app)
and [Banani reference gallery](https://www.banani.co/references) as read-only
inspiration. The review focused on hierarchy, navigation clarity, surface
layering, compact cards, progress presentation, status treatment, and readable
type. No screenshot, illustration, logo, trademarked artwork, or complete layout
from either source is included in Achiwave.

## Selected direction

Achiwave uses an original, native Android interpretation of a restrained gaming
dashboard. Deep navy backgrounds establish focus, layered blue-grey surfaces
separate navigation and content, and cool blue accents identify interaction and
progress. Pale blue-grey type keeps dense daily-use screens readable. Selected
navigation combines label, icon fill, and surface treatment so colour is never
the only cue.

The interface deliberately avoids copying Steam or any reference product. It
does not use permanent gradients, decorative HUD chrome, pixel art, fake 3D
controls, excessive glow, or external artwork. Game influence comes from clear
progress hierarchy and purposeful status language rather than ornament.

## Adopted principles

- Use one strong heading, concise supporting copy, and one obvious primary action.
- Layer content with borders and modest surface changes before adding elevation.
- Keep root navigation persistent, labelled, and recognizable at a glance.
- Present progress and status with text and shape in addition to colour.
- Preserve 48 dp controls and readable spacing on compact screens.
- Let long text wrap and screens scroll instead of shrinking type.
- Use motion and haptics as optional feedback, never as required information.

## Theme identity

The dark foundation is `#171A21` background, `#1B2838` surface, `#2A475E`
interactive surface, `#66C0F4` brand accent, and `#C7D5E0` foreground. The light
theme retains navy text and actions on neutral light surfaces. Semantic variants
for interaction, focus, status, overlays, and disabled content are centralized
in the mobile theme; pale cyan is not used as small text on white.
